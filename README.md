Mini Quiz do SPFC 
Este é um simples jogo de quiz baseado em texto, criado com JavaScript puro, para testar os conhecimentos dos torcedores do São Paulo Futebol Clube. O projeto foi desenvolvido como uma forma de praticar lógica de programação, manipulação de loops, condicionais e interação com o usuário.

O jogo está atualmente em construção.

🎮 Como Jogar
A maneira mais fácil de jogar é criar um arquivo index.html na mesma pasta do seu arquivo de script (jogo.js, por exemplo) e colar o seguinte código nele:

HTML

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mini Quiz do SPFC</title>
</head>
<body>
    <h1>Abra o console para ver o jogo ou apenas siga os alertas!</h1>
    
    <script src="seu_script.js"></script> 
</body>
</html>
Depois, basta abrir o arquivo index.html em qualquer navegador de internet. O jogo começará automaticamente através de caixas de diálogo (alert e prompt).

✨ Funcionalidades
Quiz Interativo: Perguntas de múltipla escolha sobre a história e os ídolos do SPFC.

Sistema de Tentativas: O jogador tem até 3 chances para acertar cada pergunta.

Sistema de Pontuação: A pontuação é dinâmica, recompensando acertos e penalizando erros de forma progressiva.

Feedback Imediato: O jogador é informado se acertou ou errou a resposta, além de saber sua pontuação e tentativas restantes.

Leve e Simples: Roda diretamente no navegador, sem a necessidade de bibliotecas ou frameworks.

룰 Regras do Jogo
As regras são simples e apresentadas no início do jogo:

Você tem 3 tentativas por pergunta.

Cada acerto vale +5 pontos.

Com o primeiro erro, você perde -1 ponto.

Com o segundo erro, você perde -3 pontos.

Ao errar pela terceira vez (zerando as tentativas), você perde -5 pontos.
